Prix en dinars tunisiens. Voir les conditions du Pass Ma voiture.

Comment ça marche ?

  1. Remplissez le formulaire ci-dessous (nom, téléphone WhatsApp et e-mail) : la page vous donne aussitôt votre code de commande.
  2. Payez 9 DT par D17 ou IZI avec ce code pour motif du paiement, et envoyez la preuve par WhatsApp (le message contient déjà le code).
  3. Nous activons votre code (en général sous 24 heures). Sur ce téléphone, la page du Pass le reconnaît toute seule ; ailleurs, tapez-le dans « J'ai un code ».
  4. Le Pass marche 12 mois à partir de l'activation du code.

Demander mon Pass Ma voiture

Votre nom, votre téléphone et votre e-mail servent seulement à vous envoyer votre code : ils ne sont jamais publiés ni vendus (envoi par le service Formspree ; l'e-mail de confirmation part par notre service d'envoi Resend, rien n'y est gardé). Rien n'est envoyé sans clic sur « Envoyer ».
