Conditions du Pass Ma voiture

1. Le service

Le Pass Ma voiture est vendu par l'éditeur du site « Ma voiture Tunisie ». Il permet, sur le téléphone où le code est tapé, de suivre jusqu'à 5 voitures (échéances et rappels dans l'agenda) et de tenir le carnet des dépenses (pleins, entretien, réparations) avec son bilan et son export.

2. Ce qui reste gratuit

Sans Pass, pour toujours : tous les calculateurs du site (vignette, visite technique, carburant, mutation), les échéances d'une voiture et leurs rappels dans l'agenda du téléphone.

3. Durée

Le Pass marche 12 mois à partir de l'activation du code. À la fin, les voitures et les dépenses déjà notées restent visibles sur le téléphone.

4. Prix et paiement

9 DT pour 12 mois, en dinars tunisiens ; le prix affiché au moment de la demande s'applique. Le formulaire de demande donne aussitôt un code de commande. Paiement par D17 ou IZI au 24 321 390, avec pour motif ce code de commande, puis preuve envoyée par WhatsApp au même numéro (un paiement sans le code est retrouvé grâce à la preuve). Après réception du paiement, ce même code devient le code d'accès du Pass, en général sous 24 heures ; l'activation est confirmée par WhatsApp.

5. Durée : 12 mois à partir de l'activation

Le Pass dure 12 mois à partir de l'activation du code (après réception du paiement). La date de fin exacte s'affiche sur la page du Pass et dans le message WhatsApp qui confirme l'activation. Le code peut mettre jusqu'à 10 minutes à fonctionner. Un Pass payé pendant un Pass en cours s'ajoute après la fin de celui-ci.

6. Pas de renouvellement automatique

À la date de fin, le Pass s'arrête simplement ; rien n'est prélevé. La première voiture et ses rappels restent gratuits, et les données notées restent sur le téléphone.

7. Arrêt

L'acheteur peut arrêter quand il veut en nous écrivant sur WhatsApp. Aucune période payée n'est remboursée.

8. Code d'accès

Le code d'accès est personnel : ne le publiez pas. Il est vérifié dans le téléphone et gardé sur l'appareil où il a été tapé (si le navigateur est vidé, il faut le retaper). Un code publié ou revendu peut être désactivé.

9. Limites

Les dates et montants sont indicatifs, calculés avec les règles officielles connues. Ce site n'est pas un service officiel : la date écrite sur vos documents (certificat de visite, contrat d'assurance, reçu de vignette) fait toujours foi. Les rappels viennent de l'agenda de votre téléphone : vérifiez qu'il est bien réglé.

10. Données personnelles

Nous gardons seulement : nom, téléphone, e-mail, dates du Pass et code d'accès, dans un espace privé. Ces données servent uniquement à reconnaître le paiement et à activer le code, ne sont jamais publiées ni vendues, et sont supprimées sur simple demande (WhatsApp). Sur le site public, il n'y a que l'empreinte non réversible du code et sa date de fin. Les voitures, dates et dépenses notées ne quittent jamais le téléphone. Le formulaire passe par le service Formspree ; l'e-mail de confirmation part par notre service d'envoi (Resend) ; rien n'y est gardé. Ce traitement a reçu l'accord de l'INPDP (Instance nationale de protection des données personnelles).

11. Contact

WhatsApp : 24 321 390.
